# Contributing to Drishti Nepal

दृष्टि नेपालमा योगदान दिनुहोस्

## How to Contribute

Drishti Nepal is a public accountability platform. We welcome evidence-based contributions from citizens who want to help track government performance.

### Submitting Evidence

1. **Via the Portal**: Visit [drishtinepal.com/submit](https://drishtinepal.com/submit) and fill in the submission form
2. **Required information**:
   - Which minister or cabinet decision your submission relates to
   - Clear description of your claim or correction
   - At least one verifiable source link (news article, official document, etc.)
   - Screenshots or documents supporting your claim (optional but encouraged)

### What We Accept

- ✅ Factual corrections to existing posts
- ✅ New evidence of manifesto fulfillment or violation
- ✅ Official government documents or gazette references
- ✅ News sources we may have missed
- ✅ Scholarly analysis from qualified political scientists

### What We Don't Accept

- ❌ Unverifiable rumors or hearsay
- ❌ Personal opinions without evidence
- ❌ Content that is defamatory, hateful, or discriminatory
- ❌ Copyrighted content without permission
- ❌ Spam or promotional material

### Review Process

1. **Auto-check**: Your submission is checked for completeness
2. **Community review**: Evidence quality is assessed
3. **Editor review**: Our editorial team verifies sources
4. **Publication**: Accepted submissions are incorporated with attribution

### For Developers

This is an open-source project. Technical contributions are welcome:

```bash
# Fork and clone
git clone https://github.com/rrijal1/DrishtiNepal.git
cd DrishtiNepal

# Set up development environment
cp .env.example .env
# Fill in your API keys

# Web portal
cd apps/web && npm install && npm run dev

# Agents
cd agents && python -m venv venv && source venv/bin/activate && pip install -r requirements.txt
```

### Code of Conduct

- Be respectful and constructive
- Focus on facts and evidence
- Respect political neutrality — we track ALL parties equally
- Report bugs and issues via GitHub Issues
